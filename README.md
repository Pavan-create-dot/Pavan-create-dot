## 🚀 Featured Projects

### 💰 FinFlow — Intelligent Personal Finance Aggregator
Personal finance platform built for the Indian market.
- WhatsApp Bot integration via the Meta Cloud API with HMAC webhook verification
- India-specific tax engine (Old vs. New regime, HRA exemption, FY 2024–25 rules)
- Two-tier anomaly detection on spending using Z-score + IQR
- **Stack:** Node.js, Express, PostgreSQL

### 🗣️ CiviBridge — Multilingual Civic Grievance Assistant
RAG-based assistant that lets citizens file civic grievances in English, Telugu, or Hindi and routes them intelligently to the right government department.
- Retrieval-Augmented Generation pipeline with a vector database for grievance-to-scheme matching
- Layered architecture (API → Application → Domain → Infrastructure) with JWT auth and an admin dashboard
- **Stack:** React, Node.js/Express, PostgreSQL + Prisma, ChromaDB, Gemini

### 🎤 SkillGraph — AI Mock Interview Platform
Voice-enabled mock interview app: upload a resume, pick a target role, and get AI-generated questions with an evaluation report.
- Resume parsing (any format) with an editable extraction-review step before saving
- Speech-to-text answers alongside text input
- Interview history tracked and visualized with Recharts
- **Stack:** React, Vite, TypeScript, Tailwind, Node/Express, PostgreSQL + Prisma, Clerk Auth, Gemini

### 🚆 Railway Punctuality & Delay-Cause Analytics
Data analytics project on Southern Railway routes (Vijayawada ↔ Katpadi/Chennai), covering punctuality trends and delay-cause attribution.
- Rule-based delay-cause bucketing over a 4-table relational schema
- Logistic regression delay prediction with scikit-learn
- Power BI dashboard connected live to PostgreSQL
- **Stack:** Python (pandas, scikit-learn), PostgreSQL, Power BI

### 🎵 Music Recommendation System
Content-based recommender suggesting songs from textual metadata.
- TF-IDF vectorization + cosine similarity for top-N recommendations
- Interactive real-time search deployed with Streamlit
- **Stack:** Python, scikit-learn, Streamlit
